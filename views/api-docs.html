Westpoint Security Portal API Documentation

Standardized RESTful HTTP endpoints for citizen inquiries, officer duty tracking, Internal Affairs case tracking, video bodycam streaming, and high command administrative actions.

Public Citizen APIs Officer & Shift APIs Field Training (FTO) Bodycam & Video Internal Affairs Command Center

1. Public & Citizen Endpoints

GET /api/health Public

Returns health and operational heartbeat status for process monitoring.

{ "status": "ok", "uptimeSeconds": 1420, "database": true }
GET /api/public/transparency Public

Aggregated incident counts by month and enforcement action. Strictly devoid of officer or citizen identities.

{ "byMonth": [{"month":"2026-09", "count": 24}], "totalIncidents": 142 }
GET /api/careers/positions Public

Lists all employment positions docketed by Command with open/closed status.

POST /api/careers/apply Authenticated Citizen (Discord)

Submits an employment application for an open position.

Payload: { "positionId": "POS-1001", "coverLetter": "Applicant experience statement..." }
GET /api/my-reports Authenticated Citizen (Discord)

Returns all misconduct and commendation reports filed by the signed-in citizen's Discord ID.

2. Officer Workbench & Duty Shift APIs

GET /api/officer/stats Officer Session

Aggregates all-time patrol shifts, cumulative time, longest shift, and weekly quota compliance.

{ "allTimeShifts": 34, "allTimeFormatted": "28h 15m", "quotaMet": true, "quotaPercent": 100 }
POST /api/duty/start Officer Session

Starts a duty shift after verifying active in-game Roblox presence via the Roblox API.

GET /api/push/vapid-public-key Public / Officer

Returns the VAPID public key for Web Push subscription negotiation.

POST /api/push/subscribe Officer Session

Registers a browser push notification subscription endpoint.

3. Field Training Officer (FTO) APIs

GET /api/fto/progress Officer Session

Queries the 5-stage FTO checklist and assignment for an officer or specified trainee.

POST /api/fto/signoff Supervisor / Assigned Trainer

Signs off on an FTO syllabus stage with trainer observation notes.

Payload: { "traineeId": "12345", "stage": "Radio & Code Protocols", "notes": "Demonstrated 10-codes accurately." }
POST /api/admin/fto/assign Supervisor / Command

Pairs an assigned trainer with a probationary officer.

4. Bodycam & Video Streaming APIs

POST /api/bodycam/:id/tags Officer (Owner) / Supervisor

Applies search and category tags to a recorded bodycam session.

Payload: { "tags": ["traffic_stop", "pursuit"] }
GET /api/admin/bodycam/review-queue Supervisor / IA / Command

Lists bodycam shifts filtered by review status (unreviewed, flagged, approved).

POST /api/bodycam/:id/review Supervisor / IA / Command

Submits supervisory review findings and flags shifts if necessary.

GET /api/admin/bodycam/search Supervisor / Command

Cross-officer search across shift histories by query, tag, officer name, or week key.

5. Command Administration & Security APIs

GET /api/admin/analytics High Command

8-week rollups for patrol hours, shift volumes, and 24-hour peak deployment histogram.

GET /api/admin/flags/quota-risk Supervisor / Command

Identifies officers at statistical risk of failing current week quota requirement.

POST /api/admin/action-code/request High Command

Generates a two-factor confirmation code for destructive operations and dispatches to Discord audit channel.

POST /api/admin/backup-now High Command

Triggers an immediate non-blocking SQLite database snapshot uploaded to Cloudflare R2.
