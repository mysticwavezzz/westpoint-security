API Reference

Every route this server exposes, hand-curated from server.js - not auto-generated, so keep it in sync manually when routes change. Auth tiers: Public (no session, or any signed-in Discord user - citizens included), Officer (any staff role), Supervisor, Command (High Command; implies Supervisor and Internal Affairs), Internal Affairs. Gated routes return 401 (no session) or 403 (wrong tier).

Note on confirmation codes: this is not real two-factor authentication - there's no independent second channel (SMS/authenticator/email). It's a stronger "type to confirm" pattern: a server-issued one-time code proves the confirmation happened through a live round-trip, rather than a client-side confirm() dialog that devtools could bypass. The code is returned directly to the caller; the friction is the deliberate second step, not secrecy.
